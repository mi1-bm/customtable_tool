# beatoraja 難易度表まとめカスタムフォルダ生成ツール

複数の BMS 難易度表を取得して、beatoraja のカスタムフォルダ（`folder/default.json`）に
**1つのフォルダの中へ「表 → レベル」の形でまとめて** 追加するスクリプトです。

beatoraja に難易度表をたくさん登録すると、選曲画面のルートに表が並んで見づらくなります。
このツールを使うと、表を1つのフォルダに収めて、bat をダブルクリックするだけで最新の状態に更新できます。

```
（既存のカスタムフォルダはそのまま）
obj難易度表
 ├ 表A
 │  ├ ★1
 │  ├ ★2 …
 ├ 表B
 │  ├ sl0
 │  ├ sl1 …
 └ …
```

## 特徴

- **追加の手順：** URL一覧に1行書いてbatを実行するだけで、表を追加できます。
- **読み込める表：** 表のページURL、`header.json` のURL、ローカルのファイルパスのどれでも読み込めます。
- **取得に失敗したとき：** 前回取得した分（cache）を使うので、表サイトが落ちていてもフォルダは消えません。
- **表の固定：** 更新が止まった表などは、取得せずに cache の内容で固定できます。
- **曲の並び順：** ゲーム内でLAMP順などに並べ替えたとき、同じ値の曲をタイトル順か表の掲載順に並べます。
- **動作環境：** Python の標準ライブラリだけで動きます。追加のインストールは不要です。

## 動作環境

- Windows
- beatoraja（0.8.9 で動作確認）
- Python 3.8 以降

## ファイル構成

```
update_tables.py    本体
update_tables.bat   実行用バッチ（パスの設定もここ）
table_url.txt       まとめたい表の一覧
cache/              取得した表の保存先（自動で作成）
```

beatoraja は `folder` の中で `default.json` しか読み込まないので、このツール一式を
`beatoraja/folder/` の下（例：`folder/table_tool/`）に置いても問題ありません。

## 使い方

1. ツール一式を好きな場所に置きます。
2. `table_url.txt` に、まとめたい表を1行に1つずつ書きます（書き方は下記）。
3. `update_tables.bat` を開いて、`SRC` と `DST` のパスを自分の環境に合わせます。

   ```bat
   rem 読み込む元の default.json
   set SRC=C:\beatoraja\folder\default.json
   rem 出力先
   set DST=C:\beatoraja\folder\default.json
   ```

   初めて使うときは、`DST` を別の場所にして出力内容を確認するのがおすすめです。
4. `update_tables.bat` をダブルクリックして実行します。
5. beatoraja を再起動します（`default.json` は起動時にだけ読み込まれます）。

### ほかのカスタムフォルダも作りたい場合

自作のフォルダや、別のツールで作ったフォルダも `default.json` に入れて管理したい場合は、
`DST` に `folder/default.json` を直接指定せず、**別の場所に出力して、必要なデータだけを転記**してください。

1. `DST` を `folder/default.json` 以外の場所にします。

   ```bat
   set DST=C:\beatoraja\folder\table_tool\output.json
   ```

2. bat を実行して出力します。
3. 出力されたファイルから、`ROOT_NAME` のフォルダ（`{"name": "任意のフォルダ名", "folder": [...]}` のかたまり）だけをコピーします。
4. `folder/default.json` の配列 `[ ... ]` の中の、前回貼った同じフォルダと入れ替えます。初回は末尾にカンマ区切りで追加します。

`DST` を直接 `folder/default.json` にすると、実行のたびにファイル全体が書き直されます。
既存フォルダの中身は残りますが、書式は整え直されます。
そのため、手で編集中の `default.json` や、ほかのツールが書き出す `default.json` と取り合いになることがあります。

### 実行結果の見方

| 表示 | 意味 |
|---|---|
| `[OK ]` | 取得できた |
| `[OLD]` | 取得に失敗したので、前回の cache を使った |
| `[FIX]` | `@` 指定なので、取得せずに cache を使った |
| `[NG ]` | 取得に失敗し、cache も無いのでスキップした |

## table_url.txt の書き方

```
# 行頭が # の行は無視（表をまとめから外す）
https://example.com/table.html
https://example.com/header.json
C:\beatoraja\localtable\Overjoy\header.json
file:///C:/beatoraja/localtable/laner/header.json
@https://example.com/old_table/
```

| 書き方 | 動き |
|---|---|
| 表のページURL | ページ内の `<meta name="bmstable">` から header を探す。見つからなければ同じ場所の `header.json` を試す |
| `header.json` のURL | そのまま読み込む |
| `C:\...` のパス / `file:///` | ローカルのファイルを読み込む（日本語のフォルダ名も可） |
| 行頭に `@` | 取得せず cache の内容を使う。cache が無いときだけ1回取得する |
| 行頭に `#` | その行を無視する |

- まとめの中の表は、このファイルに書いた順に並びます。
- `@` 付きの行は、`@` を外したURLで cache を探します。すでに取得したことがある表なら、`@` を付けるだけでその時点の内容に固定されます。

## 設定（update_tables.py の冒頭）

| 項目 | 説明 |
|---|---|
| `ROOT_NAME` | 追加するフォルダの名前。再実行時は、この名前のフォルダを作り直す |
| `ORDER` | 同じ値の曲の並び順。`"title"`＝タイトル順、`"table"`＝表の掲載順 |
| `REVERSE` | beatoraja は同じ値の曲を逆順に表示するため、既定では逆順（`True`）で返す。並びが逆になる場合は `False` にする |

## 仕組み

beatoraja のカスタムフォルダには SQL の条件を書くことができ、フォルダを開くたびにその条件で楽曲DBを検索します。
このツールは、各表の各レベルを `md5 IN (...)`（md5 が無い譜面は `sha256`）という条件のフォルダとして書き出しています。

`ROOT_NAME` 以外の既存フォルダはそのまま残します。ただし、JSON の書式（インデントなど）は整え直されます。

## 注意点・制限

- **段位・コースは入りません。** カスタムフォルダに書けるのは通常の条件付きフォルダとランダムコースだけです。段位を使いたい表は、beatoraja に表として登録したままにしてください。
- **登録済みの表は二重に表示されます。** 同じ表を beatoraja の難易度表としても登録していると、まとめと二重に並びます。まとめで問題ないことを確認できたら、設定画面の表一覧から外してください。
- **難易度表のレベル表示が出なくなることがあります。** 表の登録を外すと、スキンの「難易度表のレベル」表示（曲名横の★12 など）が出なくなる場合があります。
- **内容は実行した時点のものです。** 表が更新されたら bat を再実行してください。
- **beatoraja を更新するときは `folder` を上書きしないでください。** 上書きすると `default.json` が消えます。bat を再実行すれば作り直せますが、手で作ったフォルダは戻らないので、バックアップをおすすめします。
